# Copilot Instructions (GSD)

This repository follows the Get Shit Done planning workflow.

- `.planning/PROJECT.md`
- `.planning/config.json`

## Working Rules

1. Keep implementation aligned with active requirements in `.planning/PROJECT.md` and `.planning/REQUIREMENTS.md`.
2. Preserve requirement traceability when adding or modifying roadmap phases.
3. Update `.planning/STATE.md` and roadmap progress at phase boundaries.
4. Prefer lightweight, local-first architecture decisions unless requirements explicitly change.
